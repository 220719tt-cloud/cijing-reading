# 完整备份与恢复

更新：2026-10-17。入口：设置 → 完整备份与恢复。纯浏览器本地处理，不上传，不使用付费服务。

## 操作与范围

导出完整备份后，点击出现的真实「下载备份 ZIP」链接，并确认文件已保存在系统文件中。生成成功不等于系统已经保存。把 ZIP 传到另一台设备，打开阅读器设置，选择该文件，核对预览后「确认合并恢复」。默认不替换目标设备已有设置；如需采用源设备的主题、字号、背景、翻页方式、英语浓度和中文提示开关，显式勾选恢复阅读设置。

包含：全部书籍（包括当前版本的原创示例）、TXT/EPUB 原始结构化正文、基本格式、封面和插图 Blob、目录、原文位置及可用的显示位置、单词/短语/句子收藏、已掌握与未掌握状态、设置、已保存的真实英文译文。所有个人 IndexedDB 数据库版本不变，不迁移清空任何旧库。

不备份可重新获取的公共查询词典缓存，不备份已删除书籍的孤立进度/译文，也不保存系统语音、文件提供器的原文件路径、浏览器历史或其他网站数据。导出时如果发现无效进度、损坏数据或超限，会报错，不提供假装完整的部分文件。

## 合并规则

- 小说按标题、作者、语言、原文、结构化格式、插图、封面选择和目录的内容身份比较，忽略设备生成的书籍/章节编号和导入时间。格式对象的属性顺序不会影响去重。
- 相同内容复用本机已有书籍；同编号但不同内容的书籍另存为新的本地编号，不覆盖原书。章节进度与译文按源/目标章节映射。
- 收藏、掌握、章节译文采用 **add-only** 事务：已有同编号数据保留本机版本，缺少的补充。已有原文阅读进度保留。重复恢复不会新增重复内容。
- 默认仅补充缺少的全局设置；只有明确勾选时才替换设置。预览不会写数据，恢复前重新计算合并计划。
- 不同 IndexedDB 数据库与 localStorage 无法共享一个事务。每个数据库批次失败会回滚该批，但先前完成的阶段可能已保存。界面明确报告已完成数量；释放空间后重复导入补齐，不声称整次操作全部回滚。
- 恢复期间请保持页面打开并关闭其他阅读标签页，避免并发写入。恢复后重新读取书架和主题。

## 文件与安全

ZIP 内含版本化 `manifest.json`、`state.json`、分书 JSON、二进制图片与分书译文 JSON。清单逐文件记录大小与 SHA-256；原文与译文仍各自保存。校验只检测损坏，不代表文件来自可信作者。

先限制压缩大小、条目数和实际解压大小，再校验清单、CRC/哈希、版本、唯一编号、字段、章节/段落/目录/进度范围和译文源哈希。拒绝外部路径、重复文件、未引用资源及任意 localStorage 键。EPUB 恢复只接受安全结构化数据，SVG 再次移除脚本、事件和远程内容；不挂载原书 HTML。校验失败不写入数据库。

当前上限：ZIP 128 MiB、实际解压总量256 MiB、单条目24 MiB、单图片8 MiB、500本书、12,000个文件、每类学习记录100,000条。超过限制明确报错；不静默截断。大书库处理会临时占用内存，请在空间充足设备操作。备份按需加载，不把个人内容或测试 ZIP 放入生产 `dist/`。

备份未加密，包含个人小说和学习记录；请自行妥善保管。没有账号、云同步或服务器副本。浏览器清理后只能用自行保存的文件恢复。没有 PWA，不能承诺断网首次打开网站或离线刷新；网页资源已加载后，备份与恢复不需要网络服务。

## 验证

自动测试覆盖跨独立数据库恢复、封面插图与译文往返、设备编号变化、重复恢复、冲突数据保留、显式设置恢复、损坏/篡改/越界拒绝、SVG 清理、配额失败批次回滚与跨库重试、localStorage 被阻止。

内置 Chromium 已通过原生文件选择器导入完整测试备份，在独立端口来源恢复2本导入书、7条学习记录、4章译文、3项进度和3项设置；再次恢复各新增量为0。浏览器可生成完整下载链接，但自动化无法取得 Blob 链接的系统下载结果，故不把文件已保存列为通过项。iOS/Android 原生保存、分享、另一台真实设备选择该文件的完整往返，仍须真机验证。
