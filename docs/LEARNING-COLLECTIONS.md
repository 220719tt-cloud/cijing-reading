# 生词本与句子收藏 · 2026-10-17

## 使用

底部「生词本」默认打开「我的收藏」，另有「已掌握」「词库查询」入口。三个视图均可按全部、单词、短语、句子分类，并用英文或中文搜索。

- 阅读中点击英文单词、短语或本地句型，使用原有释义卡收藏／取消收藏、标记／取消掌握。
- 已导入章节译文中的英文词卡，可展开「对应英文句子／句组」，收藏完整英文及其对应中文。对应关系以真实导入片段为单位，可能是多句组成的段落，不把整段中文假装成单个词的释义，也不猜测其中每一句的对齐。
- 句型库和词库中也可以收藏。句型库操作后，父页面收藏和掌握数量直接刷新，不必手动重载网页。
- 收藏与掌握相互独立。取消收藏不撤销掌握，取消掌握不取消收藏；已取消收藏但仍掌握的内容可以在「已掌握」查看并重新收藏。
- 个人收藏优先显示最近加入的记录；每次显示 30 项，查看更多可访问全部个人记录，没有 30／100 项总量截断。查询词库依旧限制最多 100 项以控制匹配成本。
- 长英文句组显示短预览，可展开完整英文和中文原文；保存和搜索始终使用完整内容，没有截断存储。

保留原有词库查询、相关短语推荐、句型库、系统发音及阅读器功能。不增加账户、同步、付费 API、模型或部署服务。

## 存储和旧数据

沿用 `cijing-vocabulary` IndexedDB **v2** 的 favorites／mastery，未升级或清空数据库。类型新增可选 `kind: word | phrase | sentence` 元数据。旧记录在读取时兼容分类：识别原有 sentence: 编号，其他无类型记录按英文文本结构兜底；查询库自身 word／phrase 类型不变。

译文句组收藏使用英文和对应中文的 SHA-256 内容身份，同一个片段从不同英文单词点击时收藏去重，不同中文对应不会误合并。保存完整英文、中文、已有音标、类型与原有时间字段。原书、译文缓存和学习记录分别管理，没有将小说原文改写成收藏内容。

页面写入等待 IndexedDB 事务完成后再改变收藏／掌握状态。失败明确提示；个人记录读失败时禁用修改并提供重试，不假装保存成功。个人记录读取不等待词库下载，缓存词库缺失或网络不可用时，已保存的英文和中文仍可查看。旧的只有 ID 的掌握记录会在词库准备后补全显示，不凭空编造释义。

刷新、正常关闭页面并用**相同来源地址、相同浏览器配置文件**重新打开，记录仍保留。IndexedDB 不是内存临时状态。清理网站数据、无痕会话结束、系统回收或更换设备／浏览器／协议／主机／端口，仍可能使数据不可用；没有服务器备份或自动跨设备同步。
