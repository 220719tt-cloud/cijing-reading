# 常见英语句型库 · 2026-10-17

## 收录与来源

新增 **200 条去重的完整双语例句**，人物对话、心理活动、动作描写、情绪表达、环境描写各 40 条。原有 8,223 个查询词条（含 1,300 条短语）与 341 条精选词语替换规则不变。

这批内容是本项目原创编辑例句，不是商业词典摘录、小说语料提取或翻译模型输出；不虚构词频、考试来源、母语审校或绝对准确性。新增数据集合按 CC0-1.0 提供，声明在 `public/licenses/SENTENCE-NOTICE.txt`，不改变其他数据和小说的许可。

源表 `src/features/sentences/data/editorial.tsv` 明列每一组中英文，不通过脚本拼接人称、时态或大量生成释义。`node scripts/build_sentences.mjs` 仅验证和封装源表，生成 JSON 与带 SHA-256 的 manifest，不执行翻译。

实际 JSON **30,981 字节**，gzip **6,066 字节**；单份静态小库在模块中复用，不下载模型或新词典，不增加依赖，不将句型写入每本小说。浏览器实际堆内存与手机性能未作全平台测量。

## 匹配范围与浓度

- 仅在 **20%／40%** 接入：先执行现有词语／导入译文链路，再补充符合条件的整句。已选用的导入译文优先，不在英文译文内重新替换。
- 中文整句逐字匹配，必须包含已收录的句末标点；只允许段首、换行、上一句结尾或引语开头等句首边界。不做模糊匹配、同义扩展或变量填充，不把“她点了点头”套成“He nodded”。
- 对话类只用于引号内或 EPUB quote 块；其他四类用于引语外的叙述。未闭合引号按引语保护。叙述英文按小说常用过去时编辑，当前没有篇章时态推理，不能宣称适合任意文体；实时现在时叙事等场景需要之后单独设计。
- 跳过书名／指定标题、章节标题行、EPUB heading、pre 和 image。保留原有引号、空白、图片及非目标文本。
- 同一书籍与章节使用稳定排序；20% 取较小的整句预算，40% 取更大预算。整句不拆碎凑比例，有限库无法保证任意小说都能达到目标覆盖率。
- 0% 回原文；60%／80%／100% 继续使用真实章节译文缓存。本库不是通用翻译器，不用几句固定例句冒充整章翻译，也不改动原小说或已保存译文。

例如引语中的“别担心。”→“Don't worry.”，叙述中的“他点了点头。”→“He nodded.”；“他没有点头。”、“他轻轻点了点头。”、引语中的“他点了点头。”不会套用这条叙述规则。未命中整句的其他范围仍可使用已有单词／短语替换。

## 点击、查询与收藏

正文中的匹配英文句子是一个可跨行、跨页的交互节点：点击／键盘激活查看**中文原句**，可收藏、标记掌握和使用已有系统发音。点击优先于左右轻点翻页，从英文开始滑动仍沿用原翻页手势。默认不显示中文括注，不删除小说自带括号。

句型使用 `sentence:001` 等稳定 ID，收藏保存完整英文与中文原句，复用学习库 v2，不迁移／清空旧数据。收藏卡片针对句型直接使用已知中文，不必加载完整英汉词典。收藏后的句子可在既有生词本按英文或中文查询，标为“句型”，不混入相关短语推荐。

生词本底部新增可展开的「常见句型库」：支持双语搜索和五类筛选，默认显示 20 条，按需查看更多；关闭时不挂载列表，不一次渲染全部 200 条。句型库数据与英汉查询库仍分开管理。

## 阅读与离线

TXT、EPUB 使用同一显示模型。整句携带原文范围、独立显示偏移和中文原句；延用原文主锚点与显示指纹辅助位置，字号／背景／翻页模式／窗口变化走既有重排流程。EPUB 局部原文强调不错误扩散到整条译句，图片和目录原文锚点不变。

页面代码与本地小说已加载后，句型匹配、查询及学习记录可离线运行，新增功能不请求在线翻译或词典。没有加入 PWA／Service Worker，不承诺断网首次访问或整站刷新可用；系统语音是否离线取决于设备已有英语音色。

## 本轮验收

- 自动测试总计 **118 项**：200 条数据、来源／哈希／大小、每条例句匹配、五类查询、否定／人称／修饰／引语／标题边界、整句优先与不重叠、原文无漏字、离线无请求、收藏与旧数据保留、坐标往返及位置恢复。
- 测试中通过真实 TXT 与 EPUB 解析器产生 Book，验证新增整句、EPUB quote、标题保留、插图和原目录对应。
- 原创《夜里的来信》固定测试种子：31 处符合条件；20% **5 个整句 + 7 处其他词语**；40% **13 个整句 + 10 处其他词语**。同一设置稳定，选择嵌套。
- 独立浏览器来源实际导入同一 TXT 后：20% 显示 **5 个整句**，40% 显示 **12 个整句 + 9 处其他词语**。每次导入产生的本地书籍 ID 是排序种子的一部分，因此与固定单元测试种子不同；同一导入书籍重复打开的结果一致。
- 浏览器验证跨行右侧英文句子点按显示中文且不翻页、正文收藏、刷新恢复、两页翻页与 20px→22px 字号重排，原文进度滑块仍保持 73%。
- `pnpm typecheck`、`pnpm build`、`pnpm check:static` 均通过，22 个生产文件在根目录与仓库子目录的访问检查通过。360×800、390×844、1024×768 尺寸无整页横向溢出，浏览器控制台未观察到错误。真实 iOS／Android 触摸和系统语音尚需设备验收。

本轮不安装 AI 模型、不接入付费 API、不部署／上传，不开发其他阅读功能。
