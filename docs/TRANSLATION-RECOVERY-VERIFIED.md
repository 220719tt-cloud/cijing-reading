- 单个完整句组的模型格式、JSON、对齐、术语错误最多额外重试一次，第二次进一步缩短邻近上下文。多句失败仍按完整句组二分，不把对话任意切字符。

- 成功子批立即落库，下一次只计算源范围缺口；没有重翻全章的入口或失败回滚。

官方 `deploy --dry-run` 本地打包通过（15.89 KiB，gzip 5.74 KiB），未上传或更改线上状态。使用忽略的工作目录保存日志和临时配置，避免凭据、构建缓存进入仓库。

**重要：** `worker/wrangler.jsonc` 是初始化模板，含 `TRANSLATION_ENABLED: false` 和未核对的 Namespace ID，不能直接用于更新现有服务。`--keep-vars` 只保留变量，不能代替核对 AI／限流等所有绑定。获得用户登录授权后，先读取实际激活版本和绑定／变量／兼容设置，准备保留线上配置的发布方案与差异；正式激活仍须用户确认。不得用模板覆盖现有配置，也不申请或部署 Pages。

拟使用官方浏览器 OAuth 登录，仅请求账户／用户读取及 Worker 脚本管理权限（`account:read`、`user:read`、`workers_scripts:write`，以及登录所需续期权限）。这类 OAuth 权限可能涵盖账号内其他 Worker，并非令牌技术上只允许一个脚本；实际操作严格限于 `cijing-translation`。不需要把 API 密钥发送到聊天，不申请 Pages、数据库或 AI 资产管理权限。
