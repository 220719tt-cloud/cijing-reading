# 本地英语词库

当前短语扩充结果与许可见 [短语报告](PHRASES.md)：1,300 条短语，连同原有单词合并为 8,223 条。以下基础库 v1 记录保留，相关数量不代表当前合并总量。

目标：读小说时查到需要的词，不是要求用户背完大型词典。长期总量控制在约 6,000–8,000 个去重词条；本版 7,000，后续优先替换低价值词条，不以数量增长作为完成指标。

## 筛选与更新

可复现脚本：`scripts/build_vocabulary.py`。普通开发和生产构建直接使用已生成数据，不需要下载源词典。

规则：大小写／首尾空格规范化去重；要求有中文通用释义；优先上游核心标记、较高词频与四六级标签；显式保留常见小说词和短语。
排除明显人名／地名／网络词标签，去掉带指定医学、计算机、法律等技术标签的释义行；不从英文自动生成中文。
短语由 `data/vocabulary/novel-phrases.txt` 指定，并要求在原始 ECDICT 中存在。80 个候选中有 77 个存在，另外 3 个不补造释义。

复现时下载上述固定提交的 `ecdict.csv`、`LICENSE`、`README.md` 至临时目录，并将提交号写入 `commit.txt`：

```sh
python3 scripts/build_vocabulary.py /absolute/path/to/source-directory
pnpm test
pnpm typecheck
pnpm build
```

脚本校验固定提交与源 CSV 哈希；更换来源需要先审查许可与质量。修改筛选或释义后更新词库版本，确保用户缓存能更新，掌握记录保持稳定 ID。

## 两份词库分开管理

查询库：`lookup.json`，保存原英文词条、音标、经过清理的中文释义、来源考试标签、单词／短语类型。支持英文精确优先、前缀和部分匹配，中文释义子串查询。每次最多渲染 30 项；短语库扩充后支持来源词形别名，仍不做任意词形推断或在线补词。

小说候选表：编辑源为 `data/vocabulary/novel-replacements.json`；构建脚本输出独立 `replacements.json`，并复制至 `public/vocabulary/replacements.json` 以随静态网站交付。
候选有中文表达、英语词条 ID、具体词性、适用语境、排除条件和原词典释义。30 条是少量逐项核对的编辑候选，全部 `enabled: false`，不表示已具备自动消歧或可直接替换任何原句的能力。
候选必须后续通过真实小说上下文验证后再决定启用。本次未实现匹配器或正文替换；英语浓度不修改正文。

## 按需加载、离线与个人记录

- 入口：原「生词本」导航进入本地词库查询页，不增加背词任务或打卡功能。
- 查询页面本身懒加载；查询 JSON 是独立静态资源，书架和阅读器初始打开不加载词库。
- 首次打开词库时读取本网站携带的 JSON，并写入独立 IndexedDB `cijing-vocabulary` 的 `assets` 存储区；不访问第三方词典 API。
- 后续优先使用同版本 IndexedDB 缓存，不请求词库文件；缓存不可用时可尝试静态文件，并明确提示未能离线缓存。
- 已打开或可正常加载的网站可以离线查询已缓存词库；本次不实现 PWA／Service Worker，不能保证从未打开的网页或已被清理缓存的网站壳能够断网首次启动。
- 掌握状态在独立 `mastery` 存储区，按稳定词条 ID 保存，用户可标记和取消。写入事务提交后才更新界面；失败时不假装保存成功。
- 同一个词条的“已掌握”本版是整条标记，不代表掌握所有词义，也不直接驱动替换。未来可在不改动查询词典的前提下增加分义项学习记录。
- 小说数据库 `cijing-reading` 的版本、内容与结构不变。不同设备／浏览器／来源各自保存；清理网站数据会移除词库缓存与学习记录。
