# EPUB 导入与阅读支持

更新：2026-10-16。本次仅增加 EPUB，不部署或上传小说。

## 使用方法与范围

书架 → 导入小说 → 选择 TXT 或 EPUB → 检查书名、作者、内容与提示 → 加入书架。原生文件选择器兼容手机与电脑的文件入口，不读取操作系统路径。整个解析和保存流程在浏览器内完成。

支持可重排的 EPUB 2／3 文字小说：

- 从 OPF 读取标题、作者、语言、封面和 spine 阅读顺序；缺少作者显示「未知作者」，缺少封面使用既有默认封面。
- 优先使用 EPUB 3 nav，回退到 EPUB 2 NCX；保留目录层级和同一正文文件内的锚点。没有可靠目录时按正文生成。超长正文文件分为约 12,000 字符的阅读分段，目录位置相应映射，不把全书挂载到页面。
- 保留标题、段落、换行、粗体、斜体、代码、引用及基本列表文本。PNG、JPEG、GIF、WebP、AVIF 与经清理的 SVG 以本地 Blob 保存及显示；不支持或缺失图片显示占位提示。
- 排除标明的导航、封面、标题页、版权页和非线性附属页；常见 nav/toc/copyright 等文件名也做识别。原书缺乏语义标记且文件名不可辨认时，无法保证准确识别所有前言／版权内容。
- DRM 加密、固定版式 EPUB 明确拒绝；复杂原书版式、CSS、嵌入字体、脚本、音视频和交互不在本次支持范围。远程图片不联网下载。

## 复用现有阅读和学习功能

解析器输出统一的 Book / Chapter，TXT 数据无需迁移。EPUB 附加结构化块、目录和图片资源，不挂载原始 HTML，不使用 EPUB iframe 阅读器。

沿用水平分页、左右点按／拖动／触摸指针手势、四种阅读模式、14–32px 字号、六种背景、夜间模式、目录及位置恢复。只渲染当前阅读分段；当前章图片解码完成后触发重新分页。图片用 U+FFFC 占位锚点参与原文位置索引，分页测量实际图片框；字体／窗口变化后恢复到包含原锚点的新页面。

中文 EPUB 沿用原有 341 条独立替换规则和 0%／20%／40% 设置。60%／80%／100% 仍提示开发中并保留原文，没有完整英文翻译。书籍原始文本不写回。

替换英文和英文 EPUB 中的原有英文均复用现有释义卡：本地查询、音标（有则显示）、系统发音、收藏、已掌握。未收录的原生英文明确提示，不伪造释义；无可靠含义时不提供写入学习记录。中文提示开关和既有学习数据库保持不变。

## 数据、安全和性能

- 保留 `cijing-reading` IndexedDB v1 books 存储区，Book 增加可选字段；未清空书库、原有 TXT、阅读位置或 `cijing-vocabulary` v2 学习记录。写入事务成功后才确认加入书架。
- Blob 资源和小说一起保存；Blob URL 在显示时创建、卸载时回收。存储配额估算仅做预警，最终写入错误仍明确报告。
- 通过 EPUB.js 的 Packaging / Navigation 模块解析结构，通过 zip.js 解压；EPUB 依赖仅在导入 EPUB 时懒加载。本次生产解析分块约 272.13 kB，gzip 117.52 kB；未增加词库数据，也不影响初次 TXT 导入的解析加载路径。
- 导入上限：压缩文件 40 MB，声明解压总量 128 MB，压缩包 4,000 项；单 XML 4 MB、单图片 8 MB、保存图片总量 32 MB、正文计数上限约 16 MB。实际解压流也逐块检查单资源上限，拒绝重复／逃逸路径和过大内容，限制内的复杂书籍仍可能短暂占用较多内存。逐章处理并让出事件循环；关闭／换文件可取消。
- XML 禁止自定义实体和 DTD 子集；不执行脚本、事件属性、表单或 iframe。SVG 通过标签与属性白名单重新创建，移除脚本、foreignObject、外部链接和样式；不直接插入书籍提供的 SVG／HTML。外部图片、链接或 CSS 不发出网络请求。

## 验收记录

`pnpm test`：75 项通过，包含原有 TXT、设置、替换、词库和进度测试，以及本次 13 项 EPUB 测试；`pnpm typecheck` 与 `pnpm build` 通过。

自动验证覆盖：EPUB 2／3 元信息、未知作者、两种目录与回退、spine 顺序、嵌套锚点、长章分段、基本格式、图片／SVG／内嵌图片、损坏与加密文件、固定版式、实体与路径安全、解压上限、配额、取消、IndexedDB Blob 持久化与旧记录保留、原文不变、英语显示映射和点词标记。

本机内置 Chromium 浏览器检查（开发与生产构建）：

- 中文 EPUB 3：标题、作者、实际封面、2 个阅读分段、3 项目录；本地 PNG／SVG 均成功显示；脚本与 iframe 未进入正文。
- 英文 EPUB 2：未知作者与默认封面、长章拆分、目录跳转；英文原句不改写；envelope 可查看本地音标和释义。
- 20%／40% 当前测试章分别替换 97／185 处；0% 恢复原文，中文原有括号保留；提示开关、收藏与掌握可操作，测试后恢复原来的学习标记状态。
- 字号 20→22px 后重排，原文锚点保留；刷新恢复设置、书籍、图片与进度；目录可跳到章内「雨中的约定」。
- 360×800、390×844、1024×768 视口均无网页横向溢出，改变尺寸后重新分页；横向拖动从第 1 页进入第 2 页。模拟尺寸／鼠标拖动不等同真机触摸。
- 损坏 EPUB 明确报错且不可入库；随后同一入口成功导入 UTF-8 TXT、改名并读到尾句，刷新后 TXT 与 EPUB 均存在。
- 生产构建可实际解析并保存 EPUB，正文与两张本地图片成功加载。

未实测：真实 iPhone Safari／Chrome、Android Chrome／Edge、Mac Safari／Firefox 与 Windows 浏览器。采用通用 File、DOMParser、Streams、Blob URL、IndexedDB、Pointer Events 与 CSS 多栏，符合既有现代浏览器基线；最终文件提供器、触摸、内存上限及不同排版引擎仍需各平台验收，不能据本机结果宣称全部通过。
