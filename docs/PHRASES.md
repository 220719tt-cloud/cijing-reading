## 数据质量与处理

- 采用来源名单与 ECDICT **完整短语精确交叉核对**，不凭词义相近自动套用其他词条释义。
- 保留多个中文义项，规范化后合并去重；单义表达不会为了形式上“多义”而补造释义。
- 每条包含 `word`、`translation`、`meanings`、`difficulty`、`phraseType`、`category`、`sources` 和 `sourceEntries`，可追溯到来源与具体名单。
- 英文词形别名来自 ECDICT 首动词 exchange 字段，不增加独立词条；例如 thought of → think of、carried out → carry out、gave up → give up。不是完整语法分析器，不保证涵盖任意可分离短语或所有屈折形式。
- 精确词条匹配排第一，之后是来源词形别名、前缀、部分关键词；多词关键词可匹配同一短语的不同位置。中文会查询原释义和分项含义。
- 学习标签继承候选名单而非自动按词汇难度生成；类型按英语结构归类，用于学习展示，不作为替换语法规则。
- 数据已做格式、来源、重复、许可和关键样例核对，但没有宣称完成 1,300 条的语言专家逐义项审校。发现来源义项有问题应记录并修订，不能以达到数量目标为由忽略。

## 未收录与跳过清单

`data/vocabulary/phrase-exclusions.json` 保存 2,764 条被跳过候选及原因。这并不等于全部短语都错误：许多只是没有找到许可来源中的精确通用中文释义；符合条件但未进入本轮数量预算的其他候选也不被标成错误。

示例：

| 候选 | 本次跳过原因 |
| --- | --- |
| a chance of lifetime | 表达疑似缺少冠词，且没有精确中文释义，不擅自修造 |
| a lots | 表达形式不规范，未找到可靠精确释义 |
| a drastic debate | 现有许可来源没有精确通用中文释义 |
| a nominal check | 现有许可来源没有精确通用中文释义 |
| be good for | 当前来源只给出“值得、有效”，不足以准确覆盖常见用法 |
| as a result of | 当前来源“作为结果”不足以准确表达因果关系 |
| to a day | 表达较少见，本轮不作为核心学习短语，并非认定它错误 |

含未解析占位符或不支持的标点模板也暂缓，原始候选与原因保留，后续有可靠来源再处理。词条审核记录位于 `data/vocabulary/phrase-review.json`。

基础文件中原有 77 条与新短语库重叠，运行时按 ID 合并，所以不会重复展示或重复计算学习状态。
构建工具 gzip 参数不同，实际报告新增约 66.24 KB；托管是否压缩由服务器决定，原始文件约 558 KB。书架／阅读器打开不下载这两个数据文件，进入词库才并行按需加载。

继续使用既有 `cijing-vocabulary` IndexedDB、assets 缓存及 mastery 记录，不升级或清空数据库。
词库版本变为 `ecdict-phrases-1300-v2`，旧缓存自动更新后保存为 8,223 条合并数据；掌握记录保留。
有效版本缓存命中时不发网络请求。已缓存词库可离线查询；不增加 Service Worker，不能据此承诺网站壳断网首次启动。

## 复现与测试

- 候选名单、源版本和哈希：`data/vocabulary/phrase-sources/`。
- 生成：`python3 scripts/build_phrases.py /path/to/ecdict-source`。
- 从基础库重新生成：`python3 scripts/build_vocabulary.py /path/to/ecdict-source`，会接着调用短语构建，避免把总量清单恢复成旧版。
- 词条均由固定来源生成；普通 `pnpm build` 不需要外部网络或源 CSV。
- 测试覆盖：10 个指定短语、多义／中文显示、原 77 条保留、重复合并与来源保留、词形、分类、体积、哈希、离线缓存、既有 TXT／阅读设置与存储测试。
