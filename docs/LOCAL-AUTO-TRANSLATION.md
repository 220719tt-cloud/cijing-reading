# 本地自动翻译测试

更新：2026-10-17。本轮不修改Worker源码/绑定/白名单，也不部署网站。已复用现有翻译引擎、IndexedDB、阅读器和学习系统完成本地网页接入。

## 现在如何打开

本机开发服务已启动：<http://127.0.0.1:5194/#/books>。

首次测试先打开这个网址即可；不需要进入Cloudflare控制台、填写密钥或手写请求JSON。测试浏览器中保留了两本原创样本，其他浏览器配置文件会有自己的独立书架。

后续网页内的操作顺序：导入中文TXT或EPUB → 打开小说 → 点击中间显示工具栏 → 英语 → 60%、80%或100% → 首次点击“允许云翻译并开始本章”。译文进度表示已保存的原文覆盖范围，不等于当前英文显示比例。

需要暂停时点“暂停翻译”，再点“继续翻译本章”；失败时点“重试翻译本章”。100%未完整时保留中文，不能把失败或部分译文当成完整英文。切换档位和刷新复用同一缓存；0%恢复原文，20%/40%保持既有渐进处理。

关闭开发服务后，开发者可在现有项目根目录运行 `pnpm dev` 重开，固定监听127.0.0.1:5194。若端口占用会明确报错，不自动切到别的端口造成存储来源变化。`pnpm preview`仅预览生产静态文件，不提供本机转发；这不是跨设备局域网服务器，手机上的127.0.0.1也不代表这台Mac。

## 本地开发与公开网站的区别

公开构建：浏览器直接调用 `https://cijing-translation.220719tt.workers.dev/translate`；CSP只允许该确切HTTPS来源。站点仍为纯静态前端，不依赖本机服务器。

本机开发：用户已明确同意仅本机开发转发。浏览器调用自己的 `/__dev/translate`，Vite开发服务器再调用同一正式Worker，并使用已经允许的正式网站Origin。这不是将Cloudflare控制台或任意网站加入白名单；Worker的来源校验、限流、AI绑定及协议均未更改。

本机转发只接受：回环连接、准确Host及同源Origin、固定路径、POST JSON，以及通过共享协议验证的批次。上游URL固定于开发配置，不接受请求参数选择目标；不转发用户Cookie、任意来源头或重定向；限制请求32KB、响应64KB和65秒时限。取消页面请求会中断本机上游请求。开发终端只记录请求序号/句组数量，不记录小说内容。

生产构建不包含 `/__dev/translate`、本机路径或开发服务器代码，已增加静态断言检查。无需设置新的GitHub变量或Cloudflare配置。公开网页直接跨域和iPhone/Android真机仍需用户确认发布之后验收。

## 本轮修复

- 已有完整译文时，显示缓存100%和离线说明，不再误提示重新授权，也不为换档/刷新再次发请求。
- 完善暂停、继续、重试及撤销后重新允许的状态，避免旧暂停任务覆盖新任务状态。
- 修复EPUB段落编号被单独翻译而失败：真实发送 `1。` 会得到MODEL_ALIGNMENT_INVALID。纯数字/标点现在保留原样写入对应缓存，不发给AI。含正文的批次仍使用真实模型译文；全数字章节明确标记source-neutral-copy/none，不冒充AI生成。
- 每个实际云请求仍含 version:1、segments、context、glossary，普通批次最多8句/900字符，完整长句单独最多3000字符；只翻当前章并优先当前位置，继承必要上下文/术语，不整本上传。
- 没有改变小说原始内容、已有数据库版本、TXT/EPUB解析、查词、收藏、掌握及阅读位置格式。

## 真实网页验证

本轮通过现有网页操作，不以手动导入英文译文代替自动翻译：

1. 在独立127.0.0.1:5194浏览器来源导入一篇全新712字原创TXT，原先无译文。选择100%并明确允许云翻译后，实际Worker返回英文，32个句组全部自动存入原生IndexedDB。
2. 刷新、切换60/80/100，实际英文覆盖60/80/100%。0/20/40既有逻辑正常。重启开发服务后检查请求计数：刷新/换档没有新增上游请求。缓存不会因开发进程重启而丢失。
3. 导入原有中文EPUB3原创测试文件。首次因纯编号遇到MODEL_ALIGNMENT_INVALID，100%维持中文并显示重试；修复前端后同书第一章59个缓存句组（含原样编号）完成，第二章36个缓存句组完成，目录/插图/阅读页未被替换成独立新阅读器。
4. 第二章开始后实际点击暂停，界面显示已暂停、0%已保存；点击继续后达到完整100%。这次UI暂停发生在首批尚未保存时，不冒充“暂停时已有部分缓存”的证明；部分缓存后只补缺口另有自动测试。
5. 关闭云授权后仍能60%读取已完整缓存，不出现重新授权按钮；窗口字号/手机宽度改变不会启动翻译。
6. 自动译文的window点词卡实际显示中文/音标，收藏和掌握按钮可用。390×844响应式检查文档宽度390，无整页横向溢出；已恢复默认窗口。此项不等于iOS/Android真机验收。

暂停会停止后续请求，但已经在Cloudflare执行的推理仍可能消耗额度；未保存的在途批次继续时可能需要重做。已成功保存的片段不重发。格式错误仅最多一次自动重试；429/503等保持暂停等待手动重试，不循环消耗额度。免费额度及模型翻译质量的原有限制不变。
