# 自动翻译：实现、配置与验收

日期：2026-10-17。本地网页自动翻译接入已完成：新TXT和EPUB通过现有UI真实调用已部署Worker，自动写入浏览器原生IndexedDB，60/80/100换档及刷新复用、暂停继续和查词已验证。修复纯编号触发的EPUB翻译失败和完整缓存的授权提示；用户已同意仅127.0.0.1开发转发，生产仍直接连接Worker。本轮不修改Worker、不推送或部署网站。**170项测试及类型/构建/静态检查通过；公开网站直接跨域和真机仍待发布后验收**。操作与边界见 [本地测试说明](LOCAL-AUTO-TRANSLATION.md)。

## 工作方式

- GitHub Pages继续托管静态前端；可选的 `worker/translation.ts` 使用Cloudflare AI绑定调用 `@cf/qwen/qwen3-30b-a3b-fp8`，没有前端API密钥，没有用户设备模型。
- 当前使用已确认的公开服务作为默认值；可通过 `VITE_TRANSLATION_API_URL` 覆盖。覆盖地址不合法时明确报告配置错误，不发请求。首次使用需在英语面板允许把所选章节与必要上下文发送Cloudflare；随后选择任何非零档位或打开该档位的新章节自动启动。这个一次性授权按服务来源保存，不随备份转移，换设备需重新允许。
- 只翻当前章，优先当前位置所在句组，之后向后继续再补前面，绝不一次翻整本书。普通批次最多8句/900原文字符；901–3000字符的长句单独请求，保留整句；超过3000的单句明确拒绝，不能安全截断假装翻完。
- 提供相邻原文与前章末尾的有限上下文，携带当前/上一已译章的人物术语表，要求译名、关系、否定与情节一致。术语表最多60项，首次译名选择与长篇跨越多章的一致性仍需真实模型评估，不承诺绝无错译。
- 模型被要求按ID返回自然完整英文句组。Worker与前端均校验ID、长度、缺失/重复、中文冒充、术语变化和异常内容；原文范围/哈希再经现有缓存校验。只把通过校验的真实响应写入缓存，没有内置英文故事或词典逐词拼接回退。格式校验不能证明翻译忠实自然。
- 60/80复用已有句段混排与最接近比例算法；100只有正文覆盖完整才切整章英文，否则明确保留原文并显示翻译状态。图片和原导航保留；覆盖率以原文对应内容计，不是每页精确英文字符比例。
- 每批保存，进度表示已缓存原文内容。失败暂停并提供手动重试；已有部分保留，下次只补缺少范围。仅对明确MODEL_JSON_INVALID自动重试一次；其他错误不自动重试，没有无限重试。两次尝试共享65秒期限；取消或离章会停止客户端后续请求，已经在云端执行的推理可能仍消耗额度。
- 同章/同标签页任务串行，切换任何非零档位不重发已译内容；同一来源刷新复用缓存。自动写入采用事务内检查，其他标签页写入后停止并提示，避免覆盖人工译文。
- 英语面板→译文管理，可按当前章/全书范围确认删除缓存；先停止并等待当前任务。只删派生译文，不删除小说、进度、收藏或掌握。请先关闭其他阅读标签页，以免其他页面的新任务重新生成缓存。删除后暂停自动任务，需点击继续或重新进入高档才重新翻译。手动导入/导出与完整备份仍保留，自动译文和可选术语表也可备份。

## 费用、限流与风险

以下按核查时官方资料，最终以自己的控制台和服务条款为准。

- Workers AI免费账号共享每日10,000 Neurons；Free计划超限失败，更多额度需付费计划。**必须确认账号使用Free计划且未启用付费回退；本代码不是已付费账号的精确账单限额器。** [官方价格](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- 当前Qwen3模型计量约为每百万输入4,625、每百万输出30,475 Neurons。举例累计输入/输出各100万token约35,100 Neurons，超过一天免费额，按免费额度至少分多日处理；付费等价值约0.386美元。这只是token算例，不是某本小说的报价。中文字符与token不能按1:1换算，系统提示、重复上下文、术语表、失败重试也计入。实际长篇成本需要真实用量采样，不能许诺每天多少本。
- 前端同章一次只发一个请求；普通批次输出最多3072tokens，长句8192；请求32KB、响应64KB。截断或无法解析的结果报错，不缓存成完整译文。没有切换到付费/未公开接口的后备路线。
- Worker默认每个IP12请求/分钟，服务整体键60请求/分钟。原生Rate Limiting绑定是按Cloudflare位置运行的近似限流，不是全球精确账本；移动网络共享IP可能连带限流。429需至少等一分钟手动重试。[限流说明](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)
- 限制精确Origin、仅JSON POST、固定模型/任务、不允许客户端指定其他模型。**CORS不是身份认证**，攻击者仍可能伪造Origin并轮换IP消耗免费额度；公开无账号服务无法保证抗滥用。可用 `TRANSLATION_ENABLED=false` 紧急关闭，账户免费硬额度是费用边界；正式放量前应评估Turnstile/更严格的服务端预算，本轮没有假装已实现这些能力。
- Cloudflare需要处理所选文本和平台网络元数据；本Worker不写小说到公共数据库、不记录原文应用日志，并关闭Worker观测日志。平台数据处理仍适用Cloudflare政策，不能宣称云翻译完全不传原文。缓存复用无需再次发书，但首次翻译需要网络。

## 注册与配置步骤（由你确认后手动执行，本轮未执行部署）

1. 到 [Cloudflare控制台](https://dash.cloudflare.com/) 注册/登录并验证邮箱。选择Workers Free计划，在Workers AI页面查看可用模型/额度；如首次需要接受AI使用条款，由你在控制台完成。无需购买API套餐或安装AI模型。
2. 本机终端进入已有项目根目录。准备好的文件是 `worker/wrangler.jsonc`，无需新建前端项目。
3. 检查该文件：`ai.binding`为`AI`；`ALLOWED_ORIGINS`填实际网站的**来源**，例如 `https://220719tt-cloud.github.io`，不带`/cijing-reading/`路径。多个来源用逗号分隔。只有决定启用服务时，才把 `TRANSLATION_ENABLED` 从 `"false"` 改为 `"true"`。保留PER_IP/GLOBAL限流绑定；namespace_id须在自己账号内避免与其他用途碰撞。
4. 确认要发布翻译Worker时，再在项目根目录执行下面命令。Wrangler是部署工具，不是AI模型；浏览器登录授权由你完成，不需要把Cloudflare令牌给我，也不用把令牌放进项目。

   ```sh
   pnpm dlx wrangler@4 login
   pnpm dlx wrangler@4 deploy --config worker/wrangler.jsonc
   ```

   该命令将创建/更新Worker，**本轮没有运行**。若首次使用AI绑定有控制台授权提示，按Cloudflare正式流程处理。部署后记下控制台给出的 `https://cijing-translation.<你的子域>.workers.dev`，API地址必须加 `/translate`。直接在地址栏打开接口可能返回403/405，这是只允许网站发起JSON POST的设计，应通过阅读器联调。
5. 当前本机联调使用本轮经用户明确同意的开发转发：在已有项目运行 `pnpm dev`，打开 `http://127.0.0.1:5194/#/books`。无需修改Worker或白名单、无需创建`.env.local`。转发只允许同源回环请求，按现有协议向正式Worker发送所选批次；生产构建不包含此入口。完整操作与安全限制见 [本地测试说明](LOCAL-AUTO-TRANSLATION.md)。`pnpm preview`是生产静态预览，不提供这个开发转发。
6. GitHub构建已使用 `config/translation.ts` 中的公开服务默认值；无需手动添加仓库变量。若以后覆盖地址，可设置仓库Actions变量 `VITE_TRANSLATION_API_URL`，值为完整HTTPS `/translate` 地址。未设置或空白均使用已确认的默认地址。这是公开服务地址，不是密钥，禁止放令牌。
7. 你确认上传/发布后，使用GitHub Desktop推送，再手动运行已有Pages workflow。workflow已准备读取这个变量；不会因为本轮本地提交自动触发部署。重新构建很重要：地址会编入前端，生产CSP也只放行这个服务的确切来源，不能仅修改变量后沿用旧构建。
8. 如果不想开启云翻译，浏览器英语面板可撤销自己的授权；管理员可设Worker开关false。空环境变量现在仍使用已确认的默认服务，不是关闭开关。原文、20/40本地替换、已有译文和手动导入继续工作。

后端通过AI绑定调用模型，没有前端密钥。生产配置不使用Mac路径、不依赖Ollama、数据库或本地开发服务器。`pnpm typecheck`/`pnpm build`会同时检查Worker TypeScript；没有在项目依赖中加入Wrangler或模型包。
