# 网络中断后的有限恢复

2026-10-19。只修改本地前端和开发转发；不部署网站或Worker，不改数据库版本，不删除、迁移或重排任何已有小说/译文/进度。

## 当前规则

- 已确认的英文逐批事务提交到IndexedDB。每次进入任务扣除成功缓存和既有模型失败/跳过范围；正文和原文坐标不变。
- NETWORK_ERROR（包含ECONNRESET导致的fetch失败）和REQUEST_TIMEOUT不记为模型失败，也不把未处理文本记为跳过。正文继续显示原文；成功缓存不动。
- 遇到传输错误，先等待3秒、8秒、15秒的退避槽位，再请求现有Worker的OPTIONS接口；每轮整章共享最多3次探测，每次探测最长5秒，不发送小说正文、Cookie或API密钥。该接口在AI和限流逻辑前返回，不做推理。
- OPTIONS取得204后才能恢复。探测成功只代表网络/路由可达，不代表模型可用或免费额度充足。后续实际POST仍必须校验服务状态和英文结果。
- 每轮整章共享最多2次额外翻译重试，不是每个批次各重试2次。失败到达上限即暂停，剩余内容仍待翻译，稍后可手动「继续翻译本章」。全部POST含重试仍受6.1秒间隔及240次总上限约束。总预算耗尽同样暂停，不生成未请求跳过记录。
- 恢复前重新读取IndexedDB，排除等待期间其他标签页已经保存的成功范围。成功且已缓存内容不再请求；原先明确跳过的模型错误不自动补翻。格式/对齐错误仍一次处理后跳过，并继续后文。
- 403、429、503、存储失败不进入网络自动重发；保留原冷却和暂停措施。暂停、换章、关闭授权会中止等待、探测和后续请求。
- 刷新/关页不会清空成功缓存或待处理原文，重开后按缓存计算剩余范围；自动恢复预算是每次任务共享，不是跨设备/跨刷新永久预算。手动开启新任务会重新建立有限预算。

## 连接与费用边界

网络断开可能发生在Worker已执行AI、但浏览器未收到结果时。没有服务端幂等缓存时，不能保证再次发送这个**未确认批次**绝不额外计费；这就是限制额外重试次数的原因。此修复保证不重复发送**本地已确认保存**的译文，不能宣称消除了运营商、代理或Cloudflare链路的ECONNRESET。

默认探测复用现有Worker OPTIONS。开发环境的`config/devTranslationProxy.ts`也转发受同一回环地址/Host/Origin保护的OPTIONS，只允许固定Worker，不接收任意转发地址，不关闭CORS、不调用AI。开发上游POST超时为60秒，前端65秒，让转发有机会先交付明确REQUEST_TIMEOUT诊断，避免同秒抢先中断。

## 验证

自动化使用独立IndexedDB测试适配器与明确标记的英文响应替身，不读取真实浏览器书库。覆盖：成功缓存不重发、失败探测3次停止、重试2次上限跨批共享、恢复前重新读缓存、超时、鉴权/额度停止、取消、总预算不标跳过、开发来源保护。额外测试真实本机TCP socket断开，再通过OPTIONS恢复并完成剩余队列。模型响应替身不是文学翻译质量验收。

本轮不调用Cloudflare AI，不消耗既有私人小说测试的59/74请求记录；不会把独立测试脚本的网络跳过清单迁移进用户缓存。真实云端长章网络稳定性仍需后续独立验证。
