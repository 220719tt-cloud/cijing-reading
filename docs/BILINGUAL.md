# 六档英语浓度与本地双语译文

更新：2026-10-16。本轮实现译文数据、缓存、导入导出和阅读组合，不安装模型、不调用翻译 API、不部署网站。原书、查询词库和已有学习记录没有迁移或清空。

## 实际阅读行为

| 浓度 | 有对应译文时 | 没有对应译文时 |
| --- | --- | --- |
| 0% | 完整原文 | 完整原文 |
| 20% | 精选单词／短语，加符合条件的本地完整句 | 同左，不依赖导入译文 |
| 40% | 导入句组优先，搭配本地词语与匹配完整句 | 本地词语／短语和完整句库，明确没有导入译文 |
| 60% | 按完整句组选取，目标约 60% 原文内容对应英文 | 正文保留原文，标题处与英语面板明确提示 |
| 80% | 更多完整英文句组，目标约 80% | 同上 |
| 100% | 只有本章所有非空文字均有对应译文时显示完整英文，图片仍保留 | 整章原文，并明确显示“译文未完整 · 当前为原文” |

覆盖按非空白原文范围计算，表示内容覆盖程度，不是英文字符占比或翻译质量评分。句组不可拆碎，按内容重量选择最接近目标的组合；若句组过大，实际比例可能偏离并会提示。40% 的整句上限为35%，避免整段一换就成为全英文。部分译文在 60%／80% 中可使用，未译范围保留原文并标明。相同书籍、章节和设置的选择稳定，切换浓度不调用翻译，也不修改原文。模型、术语和上下文元数据保留，但当前不运行推理。

0% 的准确含义是“原文”：中文书为中文，英文原书仍为英文，不进行反向翻译。当前译文包语言方向仅支持 zh → en。译文对应标题文字块、段落或句组；工具栏的原章节名称／目录作为导航仍保留原名。

## 使用方法

1. 在 TXT 或 EPUB 阅读页轻点中间 →「英语」→「译文管理 · 导入 / 导出」。
2. 选择“当前章节”（默认）或“整本小说”，点击「导出原文模板」。文件准备后，**点击出现的下载 JSON 链接**保存文件；准备完成不代表已保存到系统文件夹。
3. 在 Mac 上人工翻译或使用自己选择的免费本地模型，填写每个片段的 `targetText`。建议以整章原文为上下文，固定人名与术语，保持对话关系和情节，按模板逐组返回。保留原有编号、`sourceText`、范围和校验值。无需为六档生成六份译文。
4. 允许先填写部分片段，保持 `status: "partial"`。空 `targetText` 表示尚未翻译；全部覆盖后程序可自动识别 complete。不能用中文复制或几句占位英文冒充完整译文。
5. 用「导入英文译文 JSON」选择文件，查看章节数量、覆盖率和英文预览，再点「保存译文到本机」。写入成功才报告保存，随后立即重新排版。
6. 可导出当前章节或整本书的「已存译文」，在另一浏览器导入**同一原文、同一章节结构**的小说后再导入译文。跨设备需要用户传递文件，不存在云同步。

更新以**章节为单位替换**包中涉及章节的旧译文，不自动拼接不同版本；未涉及章节不变，完全空白的章节会跳过，不清除旧译文。导入前建议先导出旧译文。只保存译文，不同时备份原书／插图／阅读设置／学习记录。

## 版本化格式

类型入口 `src/features/translation/types.ts`，格式 `cijing-translations`、`schemaVersion: 1`。

- `book.sourceHash`：有序原文章节的 SHA-256；`chapterCount` 校验章节结构。书籍本地 ID 和用户修改的书名不参与原文身份，允许同书跨设备对应。
- `chapters[].chapterIndex`：从 0 开始的当前规范章节顺序；标题、原文章节哈希都必须匹配。
- 每章 identity：原文哈希、语言方向、provider、modelVersion、configurationHash、contextHash。填写实际来源，不伪造模型或质量信息。
- `segments[].source`：`paragraph`、`start`、`end`，均从 0 开始；范围为段落内 UTF-16 的半开区间 `[start, end)`，不能拆开代理对，不是字节或英文偏移。
- `sourceText` 必须与原文范围逐字一致；`targetText` 是惰性纯文本，保留用户提供的换行。模板按段落内的句末标点和换行拆成句组；不会机械切成单词。
- 片段允许人工合并同一段落内相邻句子，但仍须精确覆盖对应连续原文，编号唯一且范围不重叠。不能跨段落或指向图片。
- 原文身份包含章节标题、段落和图片锚点位置，不依赖本机图片 Blob URL、设备路径或样式。更改原文／章节拆分后须重新导出模板，不猜测模糊对应。

当前限制：JSON 20 MB；整包最多 50,000 个有译文片段；单章最多 6,000 个片段、英文总量 120,000 个 UTF-16 单元；单片段原文最多 12,000、英文最多 120,000，且有异常膨胀检查。大书应分章节导入导出。支持 UTF-8 BOM，损坏 JSON、版本不符、错书、错章节、越界、重叠、错误 complete 状态均拒绝保存。防止明显中文冒充英文不代表能判断翻译忠实、人物一致或自然流畅；这些必须由译文提供者核对。

## 缓存、原文与阅读位置

- 新增独立 IndexedDB `cijing-translations` v1，`chapters` store，复合键 `[bookId, chapterId]`，按书索引。阅读只读取并校验当前章，正文只渲染当前章。
- `translationCache` 与 `translationExchange` 已有实际适配器；`TranslationProvider` 仅保留未来接口，尚无自动翻译实现。
- 包完整验证后使用一次事务写入涉及章节；同步异常、请求失败或容量不足均回滚这批写入。书库 `cijing-reading` v1 与学习库 `cijing-vocabulary` v2 不升级、不覆盖。
- 删除导入书籍时先清理该书译文，再调用原有删书流程；不删除其他书或学习记录。这两步跨数据库，不宣称是跨库原子事务。
- 原文主位置仍为 chapterId + paragraph + offset。额外保存带显示指纹的英文位置辅助值；仅当显示文本一致、映射也一致时复用，避免长译段跨页后字号变化／刷新回到段首。切换浓度或更新译文则回到原文锚点对应位置，不把英文页码或偏移当原文位置。
- 默认不增加中文括注；单词／短语点击复用原有释义卡、发音、收藏和掌握库。译句各交互词用独立的**显示偏移**标识，整句仍映射同一原文范围；卡片提供“对应中文原句”，不冒充已经完成词级翻译对齐。
- 释义优先查询现有词条、可靠词形别名与独立替换词库已核对释义。未知词明确未收录，不通过随意裁掉后缀生成释义。不会把整句原文当成每个词的中文释义。
- EPUB 继续保留结构化文字块、基本格式、目录锚点和本地图片；译文仅作为 React 文本，不能注入 HTML 或脚本。

浏览器清理／回收数据会同时影响本地译文，应保留原小说和导出的译文。没有账号、服务器备份或跨来源自动迁移。没有 PWA，已打开页面和已缓存本地数据可离线工作，不承诺断网首次加载／整站刷新。

## 验证与边界

本轮 `pnpm test` 103 项通过，`pnpm typecheck`、`pnpm build` 和 `pnpm check:static` 均通过。静态检查覆盖全部 21 个生产文件在根目录与 `/cijing-reading/` 子目录下的访问、相对资源、CSP、许可及常见本机路径／密钥模式。测试覆盖全部六档、完整／部分／缺失译文、稳定选择、原文不变、TXT 换行、跨设备 ID、错书拒绝、代理对边界、容量失败原子回滚、章节更新／读取／导出往返、旧书库／学习数据保留、英文点击坐标以及长译段位置恢复。

生产页面在独立测试来源使用真实 TXT／中文 EPUB 夹具导入对应译文，验证 100% 正文英文、EPUB 两章独立读取、目录跳转、插图、刷新持久化、点词不翻页、收藏／掌握刷新恢复、字号变化、键盘和拖动翻页。示例《月亮邮局》中 40% 显示 3 个英文句组并补充词语替换；60% 为 6 个句组（约 64% 原文覆盖）、80% 为 7 个（约 81%）、100% 为 9 个。不是通用小说质量或手机性能保证。

内置浏览器验证了导出文件生成、Blob 下载链接和文件名；JSON 序列化再导入的往返通过自动测试。内置浏览器的原生下载事件未返回，实际系统保存对话框及 iOS／Android 文件保存尚未验收，不能称为真机下载已通过。最终生产构建在 360×800、390×844、1024×768 尺寸均无整页横向溢出；`opened` 可关联现有 `open` 释义且点击不翻页。未观察到浏览器控制台错误。真实 Safari、Android 浏览器仍须设备验收。

测试数据在 `tests/fixtures/translations/`：`moon-en.json`、`utf8-en.json`、`epub-en.json`，只对应本项目原创示例／夹具，人工编写并逐项映射，不是模型输出，不会自动安装或打入网站。重建命令：

```sh
node --experimental-strip-types scripts/build_translation_fixture.mjs
```

例如在《月亮邮局》导入 `moon-en.json` 后即可免费验收高浓度阅读。任意用户小说仍需先提供可靠英文，阅读器不会自己凭空生成。未来免费本地模型可作为独立工具提供译文，但本轮没有安装或选择模型，也不能承诺模型所需下载、速度和质量。
