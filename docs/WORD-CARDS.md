# 中文提示开关与阅读释义卡片 · 2026-10-16

本轮在现有项目上修改显示、点击交互和本地学习记录；不更改小说、词典原数据、替换映射或英语浓度选取策略。

## 行为

- 默认不生成系统中文括注；旧阅读偏好缺少 `chineseHints` 时也按关闭处理。
- 英语面板新增「中文释义提示」开关。与其他阅读偏好一起写入 `cijing-reader-preferences` localStorage，刷新恢复。开启后沿用本章首次遇到未掌握词的提示策略；重复词和已掌握词减少提示。
- 不采用正则删除括号。显示模型只决定是否附加自己的提示，原小说中的 `（中文括号）`、`(原文备注)` 保持完整；0% 返回完整原文。
- 每个替换块保留英文、中文和原始范围。英文单词或短语是可点击、支持键盘 Enter／空格的行内元素，能自然换行和跨页；点击后查看「本句含义」。只有本地查询库确有音标才显示，复数命中原形条目时明确标注原形音标。
- 首次打开卡片才加载完整查询库；没有对应查询条目或离线加载失败时，仍显示替换映射已核对的本句中文，不编造其他词义和音标。
- 收藏和掌握按钮等待本地事务成功才改变状态；失败明确提示。关闭按钮、Escape、点击卡片外部都能关闭。

## 点击与排版

`readerGesture` 区分轻点、滑动、长按和竖向拖动。轻点英文的优先级高于左右侧翻页；从英文开始的水平滑动仍执行翻页。系统点击捕获和手势处理共用显示偏移定位词条（data-word-start），同时保留原文范围，不用显示页码标记词条。译句中的多个词可对应同一原文句组，仍用各自显示偏移区分。

`textNodes.ts` 为行内英文与原文文本节点建立连续 UTF-16 索引；分页、滚动位置捕获、章节滑块、字体及提示变化后的恢复共同使用此索引，再映射到原文位置。
不是仅取 `firstChild` 的文本，也不把带释义的显示偏移写入小说进度。覆盖翻页的临时视觉克隆不接收焦点或点击。

## 本地学习存储

沿用 `cijing-vocabulary` IndexedDB，版本 1 → 2，只增建 `favorites` store；原有 `assets`、`mastery` 都保留，不接触小说数据库。

- 收藏按原形／词条 ID 去重，保存英文、本句中文或词典释义、已有音标和收藏时间。
- 继续复用 `setMastered`；增加可选词条摘要，用于展示查询精选库之外、从阅读器标记掌握的表达。兼容旧的只有 ID 和掌握布尔值的记录；后续只改状态不会丢掉已有摘要。
- 生词本增加「只看收藏」，保留「只看已掌握」；两个筛选可组合。查询词库之外的个人收藏或掌握表达也能显示，已有完整词典义项不会被简义覆盖，不修改查询库的 8,223 条数据或计数。
- 没有账号、服务器、跨设备同步。学习记录仍属于当前设备、当前浏览器的网站来源。

## 系统发音

使用标准 `speechSynthesis` / `SpeechSynthesisUtterance`，由用户点击同步发起，优先本地英语音色，再使用设备提供的其他英语音色。无任何已枚举音色时允许浏览器按 en-US 选择；只有中文音色时明确提示添加英语语音，不用中文发音冒充。

不支持 API、播放错误、15 秒内没有完成回调都给出提示；卡片关闭时取消本卡片的发音。未引入付费 API、在线翻译、听书或语音服务。可用音色、离线能力和实际可听输出由浏览器／系统决定，可能需要用户先安装系统英语语音包。
